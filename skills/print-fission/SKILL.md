# 印花裂变

这是一套做法，不绑定生图脚本。

## 读取元素

看用户给出的印花图。多张只留共同特征，一张就读这一张。记下主体元素、构图和风格：题材、单枚或连续、线条、配色、疏密、材质、笔触。

写成一条英文底稿，只用于后面改写。

## 改写

默认 4 张。用户指定张数或风格时只改变量。每张单独一条英文提示词。主体元素整句保留，只改风格和细节。提示词用完整英文句子。内容只有最终提示词。

```text
Create one standalone print pattern of [原样保留的主体元素].
[这一张改写后的风格与细节].
Use the reference prints only as the source of those motifs.
Fill one continuous pattern, with no collage, no grid, no contact sheet, no text, and no watermark.
```

每张都是一张独立图案，基于参考印花改写。

## 检查

主体还在，风格各自不同，没有拼贴、文字或水印。不合格的只重做那一张。
