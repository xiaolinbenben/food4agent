## Facts Checked While Drafting

- The Global Help main page organizes seller knowledge into sign-up, products, prices, fulfillment, promotion, analytics, finance, customers, fees, quality, partners, seller app, Global University, API, and contracts.
- Product categories affect sales commissions, characteristic sets, and search result position; wrong category can lead to moderation rejection.
- Characteristics affect navigation, search, filters, and comparison. Ozon warns against irrelevant search keys and unnecessary values.
- Required characteristics must be specified; missing mandatory characteristics can fail moderation.
- Product description should be accurate and helpful, and should not contain contact info, price/discount text, large keyword lists, unsupported promotional claims, or replica/fake wording.
- API upload supports product import and status checks; official docs state `POST /v2/product/import` and `POST /v1/product/import/info`.
- Seller API can automate product upload, price updates, stock updates, and reports; changes can pass moderation and appear with delay.
- Search analytics includes tools for checking whether a product is displayed for a query/region and for analyzing ranking factors.
- Search-query analytics includes frequency, cart additions, conversion to cart, average price, and no-result share.
- Ozon ranking analysis distinguishes query matching, reviews, price, popularity, boosting factors, and paid promotion.
- Ozon search-page ads use relevant search phrases, phrase moderation/status, phrase reports, and negative words.
- Fees and tariffs vary by seller country, category, scheme, price/date, and current official table.
