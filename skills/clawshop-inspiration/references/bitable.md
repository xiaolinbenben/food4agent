# Bitable 字段速查

> 数据来源：clawshop-data-manager。如有字段名疑问，以 feishu_bitable_list_fields 返回值为准。

## ⚠️ 主字段名说明

主字段名由 `clawshop-data-manager` 建表时配置，每个店铺不同。
写入时**必须以 `feishu_bitable_list_fields` 返回的第一个 `is_primary: true` 字段名为准**，
禁止猜测或硬编码字段名。

## Token 获取

```
gateway config.get path=skills.entries.clawshop-data-manager.env
→ 取 CLAWSHOP_APP_TOKEN 和 CLAWSHOP_TABLE_ID
```

> ⚠️ `echo $CLAWSHOP_APP_TOKEN` 在隔离 session 中读不到，必须用 gateway 接口。

## 候选状态（严格7个，禁止扩展）

| 状态值 | 写入时机 |
|--------|---------|
| `⏳待评估` | 选品入库 |
| `🔄铺货中` | 1688搜品成功，铺货已提交 |
| `已上架` | 巡检确认抖店在售 |
| `已出单` | 订单数 ≥ 1 |
| `已下架` | 14天0单自动下架 |
| `❌不符合标准` | 搜品失败/无货源 |
| `❌铺货失败` | 铺货提交后被平台过滤 |
