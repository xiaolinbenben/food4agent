# 💰 差价流 · 零售平台价差

## 来源标识

| 字段 | 值 |
|------|----|
| 来源方法 | `💰差价流` |
| 来源渠道 | 淘宝 / 拼多多 / 京东（具体平台） |

## 目标

找到 **2件** 零售平台热销、1688进价低、差价倍率高的商品。

---

## 选品标准

| 指标 | 目标 |
|------|------|
| 零售售价 | ≥ ¥15 |
| 预估1688进价 | ≤ ¥8 |
| 加价率 | > 200%（即售价 > 3× 进价） |
| 销量表现 | 该平台有一定销量/好评，证明需求存在 |

---

## 执行步骤

### Step -1：Bitable Bootstrap（取 token）

```
gateway config.get path=skills.entries.clawshop-data-manager.env
→ 取 CLAWSHOP_APP_TOKEN、CLAWSHOP_TABLE_ID
→ feishu_bitable_list_fields 验证连通性
```

---

### Step 1：搜索零售平台热销品

用 `web_search` 搜索（每次换词，参考 memory/clawshop-learnings.md 避免重复）：

**搜索词模板**：
- `「[品类] 订单暴增 [年份]」` / `「[品类] 销售额同比+X%」`（比「热销」更精准，能命中真实爆款）
- `「拼多多爆款 [品类] 万单 [年份]」`
- `「[节日/季节] 创意小礼物 热销 性价比」`

**3月参考关键词**：清明出游摆件 / 春季桌面好物 / 解压玩具 / 女生送礼创意小物

每次至少搜 **3 个不同关键词**，从结果中找出有明确销量/好评佐证的具体商品名。

---

### Step 2：预估1688进价

**不需要搜1688**，根据商品品类直接估算：

| 品类 | 预估进价 |
|------|---------|
| 简单塑料/硅胶玩具（扭扭乐/捏捏乐） | ¥2-5 |
| 小金属摆件/挂件 | ¥3-8 |
| 小陶瓷/树脂摆件 | ¥4-10 |
| 创意纸品/贴纸 | ¥1-3 |
| 布艺/毛绒小挂件 | ¥3-6 |
| 木质工艺品 | ¥3-8 |
| 电子小玩具（简单） | ¥5-12 |

估价原则：取区间**中低位**，宁可保守。含运费预估 +¥2-3。

> ⚠️ 搜到的价格可能是限时促销价，以商品详情页「X人付款」旁边的**日常标价**为准，忽略「限时补贴」价。

---

### Step 3：计算加价率

```
加价率 = (零售售价 - 预估进价) / 预估进价 × 100%
```

- 加价率 > 200% → ✅ 候选入库
- 加价率 ≤ 200% → ❌ 跳过，换下一个

---

### Step X：入库前查重

调用 `feishu_bitable_list_records(app_token, table_id)` 拉全量，
商品名关键词匹配（任意状态）→ 已存在则跳过，换下一个候选品。

### Step 4：入库

调用 `feishu_bitable_create_record`，`评估备注` 格式：

```
零售平台：[平台] 售价¥X（[销量佐证，如月销X件/好评X条]）
预估1688进价：¥X（含运费，品类估算）
预估加价率：X%
搜索来源：[使用的搜索关键词]
```
