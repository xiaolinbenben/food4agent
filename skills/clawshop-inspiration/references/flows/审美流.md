| 字段 | 值 |

## 目标

通过小红书 MCP 找到 **2件** 有颜值需求、有求购声音的具体商品。

---

## 执行步骤

### Step -1：Bitable Bootstrap（取 token）

执行 `gateway config.get path=skills.entries.clawshop-data-manager.env`，
取出 `CLAWSHOP_APP_TOKEN` 和 `CLAWSHOP_TABLE_ID`，
然后调用 `feishu_bitable_list_fields(app_token, table_id)` 验证连通性。
- 成功 → 继续
- 失败 → 按 `clawshop-data-manager/SKILL.md` Step 3 重新建表

### Step 0：检查小红书 MCP

```bash
ps aux | grep xiaohongshu-mcp | grep -v grep
```

进程存在则继续确认：

```bash
python3 {baseDir}/../xiaohongshu-mcp/scripts/xhs_client.py status
```

- ✅ 正常 → 继续
- ❌ 未运行 / cookies 过期 → **立即终止**，汇报「小红书 MCP 未就绪，需人工检查」

### Step 1：关键词策略

从下方品类池 + 修饰词池**动态组合**关键词，至少搜 3 个不同关键词：
- 结合当前季节和热点（3月=春季、女神节余热、春游等）
- 每次运行不重复上次关键词（参考 memory/clawshop-learnings.md）
- 每次搜索前随机等待 5-10 秒（防限流）

**品类池**：桌面摆件 / 车载摆件 / 家居挂件 / 钥匙扣 / 解压玩具 / 创意礼物 / 少女心好物 / 治愈系小物

**修饰词池**：氛围感 / 高级感 / ins风 / 复古 / 可爱 / 治愈 / 性价比 / 送礼 / 小众 / 不撞款

**示例组合**：「治愈系桌面摆件」「ins风钥匙扣 不撞款」「送礼氛围感小物」

### Step 2：筛选标准

从搜索结果中筛选帖子：
- ❤️ 收藏数 ≥ 300
- 💬 评论数 ≥ 20

进入帖子详情，**重点扫描评论区**，找到含以下信号的帖子：
- 「在哪买」「求链接」「哪里有」「怎么买」「淘宝搜什么」
- 大量点赞的求购评论（说明购买意向强）

**必须找到 2 件具体商品**（有明确商品名，不是泛类目描述）。

### Step X：入库前查重

调用 `feishu_bitable_list_records(app_token, table_id)` 拉全量，
商品名关键词匹配（任意状态）→ 已存在则跳过，换下一个候选品。

### Step 4：入库

`评估备注` 填写：

```
来自帖子：[标题/链接]
收藏X / 评论X / 求购评论：「[代表性评论原文]」
颜值亮点：[1句话]
```

### Step 5：汇报补充

- 本次使用的 3 个关键词
- 每件商品的收藏数 + 求购评论数
- 帖子链接（可选）
