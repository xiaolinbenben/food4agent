# 🌍 逆向流 · 海外平台反向选品

## 来源标识

| 字段 | 值 |
|------|----|
| 来源方法 | `🌍逆向流` |
| 来源渠道 | Amazon / TikTok（具体平台） |

## 目标

从海外平台热销榜中，找到 **2件** 国内还未爆、但1688有货源的潜力商品。

---

## 执行步骤

### Step -1：Bitable Bootstrap（取 token）

执行 `gateway config.get path=skills.entries.clawshop-data-manager.env`，
取出 `CLAWSHOP_APP_TOKEN` 和 `CLAWSHOP_TABLE_ID`，
然后调用 `feishu_bitable_list_fields(app_token, table_id)` 验证连通性。
- 成功 → 继续
- 失败 → 按 `clawshop-data-manager/SKILL.md` Step 3 重新建表

> ⚠️ `echo $CLAWSHOP_APP_TOKEN` 在隔离 session 中读不到，必须用 gateway 接口。

### Step 1：搜索海外热销（2 次并发）

```
web_search: "amazon best seller home decor novelty gifts desk [当前月份] 2026 trending"
web_search: "tiktok viral home decor desk accessory satisfying gift [当前月份] 2026"
```

> Etsy 以手工定制品为主，不适合1688代发，**不搜 Etsy**。

**筛选条件**：
- 适合我们品类：摆件 / 挂件 / 礼品 / 解压玩具 / 家居生活小物
- 非专利/非品牌独占（判断1688有货）
- **直接从搜索结果摘要识别具体商品名，无需 web_fetch 打开页面**

### Step 2：评估国内现状（每件 1 次搜索）

```
web_search: 「[商品中文名] 淘宝 月销」
```

**快速判断**：
- 月销 > 5000 → `🔴 已爆`，跳过，换下一候选
- 月销 < 1000 或搜不到中文名 → `🟢 蓝海`，优先入库
- 介于两者 → `🟡 红海中`，可跟进

> 「Made in China」≠「国内已爆」，需独立判断国内搜索量。

### Step X：入库前查重

调用 `feishu_bitable_list_records(app_token, table_id)` 拉全量，
商品名关键词匹配（任意状态）→ 已存在则跳过，换下一个候选品。

### Step 4：入库

`评估备注` 填写：

```
来源：[平台] [商品链接或搜索词]
海外数据：[reviews数/sales数/价格区间]
国内现状：🟢蓝海 / 🟡红海中（说明原因）
1688可行性：[初步判断 + 预估进价]
```

### Step 5：汇报补充

- 每件入选商品：名称 + 来源平台 + 国内机会判断
- 跳过商品：名称 + 跳过原因
