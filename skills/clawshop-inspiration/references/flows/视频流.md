# 📹 视频流 · 短视频带货热品

## 来源标识

| 字段 | 值 |
|------|----|
| 来源方法 | `📹视频流` |
| 来源渠道 | 抖音 / 快手（具体平台） |

## 目标

从抖音/快手热门带货视频评论中，发现 **2件** 评论区求购声音强烈的商品。

---

## 执行步骤

### Step -1：Bitable Bootstrap（取 token）

执行 `gateway config.get path=skills.entries.clawshop-data-manager.env`，
取出 `CLAWSHOP_APP_TOKEN` 和 `CLAWSHOP_TABLE_ID`，
然后调用 `feishu_bitable_list_fields(app_token, table_id)` 验证连通性。
- 成功 → 继续
- 失败 → 按 `clawshop-data-manager/SKILL.md` Step 3 重新建表

### Step 1：搜索近期带货热品

`web_search` 搜索（每次**换品类关键词**，参考 memory/clawshop-learnings.md）：

```
web_search: 「抖音 [品类] 话题 热搜 [年份][月份]」   ← 最有效，话题词出现即大规模视频存在
web_search: 「抖音 最火 [品类] 2026 带货视频 求链接」
web_search: 「[新闻/行业媒体] 抖音爆款 [品类] 点赞 [季节]」  ← 能获取真实点赞数据
```

> ⚠️ `web_search` 无法直接拉抖音视频数据（点赞/播放量），只能间接推断。抖音页面无法 web_fetch（JS渲染）。信号可信度：新闻引用具体数据 > 搜索词级别话题 > 一般搜索结果。

**品类轮转**（每次选 2-3 个不同品类）：
摆件 / 挂件 / 解压玩具 / 钥匙扣 / 家居小物 / 创意礼品 / 治愈系好物

**3月特别关注**：春季出游好物 / 学生开学用品 / 办公桌面好物

### Step 2：筛选信号

从搜索结果中识别带货信号强的商品：

**强信号（优先选）**：
- 评论区出现「求链接」「哪里买」「已下单」「已囤货」等
- 视频点赞 > 10万 或 评论 > 1000
- 博主反复提该商品（而非一次带过）

**弱信号（可选，需补充判断）**：
- 视频播放量 > 50万
- 商品出现在「好物分享」「家居必买」等盘点类视频

### Step X：入库前查重

调用 `feishu_bitable_list_records(app_token, table_id)` 拉全量，
商品名关键词匹配（任意状态）→ 已存在则跳过，换下一个候选品。

### Step 4：入库

`评估备注` 填写：

```
视频来源：[抖音/快手] + [博主名/视频标题或话题词]
热度数据：点赞X / 评论X / 播放量X（若无精确数据注明「话题词级别」）
求购信号：「[代表性评论原文或描述]」
⚠️ 信号质量：[高/中/低]（新闻引用数据=高；话题词存在=中；一般搜索推断=低）
```

> ⚠️ 特别注意：含活体植物（苔藓/多肉生态瓶等）商品需在评估备注中注明「需确认是否有活体植物运输资质要求」。

`来源渠道` 填：`抖音` 或 `快手`（具体哪个平台）

### Step 5：汇报补充

- 本次搜索关键词
- 每件商品：名称 + 视频平台 + 热度数据摘要
