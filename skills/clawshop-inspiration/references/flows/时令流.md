# 📅 时令流 · 节日热点

## 来源标识

| 字段 | 值 |
|------|----|
| 来源方法 | `📅时令流` |
| 来源渠道 | `抖音节日热搜` |

## 目标

找到 **2件** 与未来 15 天节日/热点强相关的应季商品。

---

## 执行步骤

### Step -1：Bitable Bootstrap（取 token）

执行 `gateway config.get path=skills.entries.clawshop-data-manager.env`，
取出 `CLAWSHOP_APP_TOKEN` 和 `CLAWSHOP_TABLE_ID`，
然后调用 `feishu_bitable_list_fields(app_token, table_id)` 验证连通性。
- 成功 → 继续
- 失败 → 按 `clawshop-data-manager/SKILL.md` Step 3 重新建表

### Step 1：确认当前日期 + 判断节日窗口

> ✅ 直接用日历知识判断，**无需 web_search 查节日日期**，节日信息稳定无需联网验证。

**筛选规则**：
- ✅ 只选 **未来 ≤ 15 天** 的节日/热点
- ❌ 已过的跳过，不管多热门
- ✅ 优先选距今 3-10 天的（备货时间充裕，窗口期合适）
- ⚠️ 距今 **≤ 3 天**的节日：备注时效风险「需确认供应商发货时效≤24h」，不跳过，由店主决定

**常见节点参考**（需根据实际日期判断）：
- 3月：妇女节(3/8) · 白色情人节(3/14) · 春分(3/20)
- 4月：清明(4/5) · 愚人节(4/1)
- 5月：劳动节(5/1) · 母亲节(第二个周日)
- 6月：端午 · 儿童节(6/1) · 父亲节
- 其他：入学季 / 毕业季 / 双11 / 双12 / 元旦 / 春节

### Step 2：选品

对每个节日/热点，找 **1件** 强相关且适合我们品类的商品：

**适合品类**：摆件 / 挂件 / 礼品 / 解压小物 / 家居生活

**判断是否强相关**：
- 商品名/卖点中包含节日关键词，或
- 节日场景下的消费高频品（如情人节→爱心摆件，清明→踏青/户外小物）

**不要选**：食品、服装、大件家电

### Step X：入库前查重

调用 `feishu_bitable_list_records(app_token, table_id)` 拉全量，
商品名关键词匹配（任意状态）→ 已存在则跳过，换下一个候选品。

### Step 4：入库

`评估备注` 填写：

```
对应节日：[节日名]（距今X天，X月X日）
出单理由：[1句话，为什么这个节日会买这件商品]
时间窗口：[X天]
```

### Step 5：汇报补充

- 本次识别的节日窗口列表（名称+距今天数）
- 每件商品名 + 对应节日 + 入库 record_id
