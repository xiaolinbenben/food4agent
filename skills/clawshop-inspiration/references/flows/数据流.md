## 目标

从抖音商机中心找到 **2件** 四维全达标的商品。

---

## 执行步骤

### Step -1：Bitable Bootstrap（取 token）

执行 `gateway config.get path=skills.entries.clawshop-data-manager.env`，
取出 `CLAWSHOP_APP_TOKEN` 和 `CLAWSHOP_TABLE_ID`，
然后调用 `feishu_bitable_list_fields(app_token, table_id)` 验证连通性。
- 成功 → 继续
- 失败 → 按 `clawshop-data-manager/SKILL.md` Step 3 重新建表

### Step 0：进入商机中心并验证登录

```
browser open https://fxg.jinritemai.com/ffa/bu/NewBusinessCenter profile=openclaw
```

快照确认已登录（看到商机列表即可）。

### Step 1：四维选品

**排序策略**（依次尝试，每种最多翻 3 页，凑够 2 件即停）：
1. **为你推荐**（优先！命中率最高，平台已过滤品类匹配商品）
2. 增速快（找爆发期商品，适合发现新趋势）
3. 竞争小（蓝海品，但搜索增速普遍低，超过 2 页无达标即放弃）
4. 成交高

> ⚠️ 「竞争小」排序虽然需供比极高，但这类商品多为冷门新品，搜索增速通常只有
> 30-35%，难以达到 50% 门槛。优先用「为你推荐」命中率更高。

**禁止操作**：
- ❌ 碰类目下拉菜单
- ❌ 点「发相似品」/「找货源」/「发布商品」
- ✅ 只点商品行的 `[class*=nameWrap]` 内层 title span 打开详情弹窗

**点击方式（用 JS，避免触发错误弹窗）**：

```javascript
// 按索引点击第 N 个商品（0-based），精准点 title span
document.querySelectorAll('[class*=nameWrap]')[N]
  ?.querySelector('[class*=__bu_card_title__], [class*=name-]')
  ?.click()
```

点击后立即关闭「关联已有相似新品」弹窗（它会自动叠加弹出）：

```javascript
// 等待 500ms 后执行
Array.from(document.querySelectorAll('button.auxo-drawer-close'))
  .map(b => { b.click() })
```

然后读「商机详情」drawer 数据：

```javascript
Array.from(document.querySelectorAll('[class*=drawer],[class*=Drawer]'))
  .find(d => d.innerText.includes('商机详情'))?.innerText?.substring(0, 700)
```

**四维达标条件（全部满足才入选）**：
- 成交增速（「成交金额 较上周期」）> 30%
- 搜索增速（「搜索次数 较上周期」）> 50%
- 需供比趋势（「需供比 较上周期」）为正
- 其他维度（在线商品量等）无明显下降

> 注意：表格列「成交增速」= 成交金额较上周期。「搜索增速」只在详情弹窗里，
> 表格不显示，必须点进去看。

### Step X：入库前查重

调用 `feishu_bitable_list_records(app_token, table_id)` 拉全量，
商品名关键词匹配（任意状态）→ 已存在则跳过，换下一个候选品。

### Step 3：入库

**3-0 查重（必须）**

```
feishu_bitable_list_records(app_token=<Step-1取到的token>, table_id=<Step-1取到的table_id>)
→ 用商品名关键词（2-4字）匹配主字段（字段名见 bitable.md）
→ 任意状态命中 → 跳过，换品
```

**3-1 写入记录**

用 Step -1 取到的 `app_token` 和 `table_id` 调用 `feishu_bitable_create_record`，`评估备注` 填写：

```
四维数据（近30天）：成交增速X% / 搜索增速X% / 需供比X(+X%) / 在线商品量X-X(+X%)
推荐理由：...
商品类目：...
高动销价格带：¥X-¥X / 高动销人群：...
参考热卖品：[商品名] ¥X 已售X件
排序策略：[使用的排序] 第X页
```

**3-2 确认写入**

`feishu_bitable_create_record` 返回 `record_id` 即写入成功，记录下来用于汇报。
