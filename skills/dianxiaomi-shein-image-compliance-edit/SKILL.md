# 店小秘 SHEIN 图片合规编辑

用于在店小秘 SHEIN 产品编辑页修复变种图片区的图片数量、尺寸和比例报错。

## 前提

- 必须使用 `chrome:control-chrome` 操作用户真实 Chrome 会话。
- 默认用户已登录店小秘；如果页面要求登录、验证码或权限不足，停止并让用户处理。
- 只处理图片合规相关入口。不要点击 `保存并移入待发布` 或 `发布`，除非用户明确要求。
- 用户明确要求保存时，点击商品页普通 `保存` 后，必须回到 `变种图片` 表格定向复查。

## 合规要求

- 细节图支持 `1:1`、`3:4`、`4:5`、`13:16`；图片像素边长必须在 `900px-2200px` 范围内。
- 每个颜色至少选择 2 张细节图。
- 方形图支持 `900 x 900` 至 `2200 x 2200` 的 `1:1` 方图。
- 色块图若已显示 `80 X 80`，本轮通常不需要处理。

## 定位变种图片表格

1. 接管标题为 `店小秘--编辑SHEIN产品`、URL 包含 `/web/sheinProduct/edit` 的 Chrome 标签页。
2. 滚动或点击右侧锚点到 `变种图片`。
3. 找到表头包含 `细节图 编辑`、`方形图 编辑`、`色块图 编辑` 的表格。
4. 按颜色逐行读取：
   - 颜色名，例如 `Blue`、`Black`。
   - 细节图数量，例如 `【1 / 11 图片】` 或 `【2 / 11 图片】`。
   - 每张图下方尺寸，例如 `1000 X 1000`、`1440 X 1440`、`800 X 800`。
   - 红色报错文案，例如 `至少选择2张细节图` 或方形图尺寸要求。

## 方形图尺寸修复

优先使用单张缩略图下方的蓝色魔棒，不要依赖表头批量入口。

1. 在目标颜色行的 `方形图` 缩略图下方点击蓝色魔棒。
2. 在可见菜单中点击 `小秘美图`。
3. `小秘美图` 会打开新标签页：
   - URL: `/web/newImageEditor`
   - 主体是 iframe: `/api/meituv2/editor.htm`
4. 切换并读取新标签页后操作 iframe。
5. 点击左侧 `调整尺寸`。
6. 对 800 x 800 方形图，使用可靠路径：
   - 点击预设 `方形主图 (1000 x 1000)`。
   - 点击 `应用`。
   - 点击右上 `保存` 下拉。
   - 点击 `保存并应用`。
7. 编辑器标签页成功保存后通常会自动关闭。回到商品编辑页，确认该方形图显示为 `1000 X 1000` 或其他合规尺寸。

已验证问题：
- 在小秘美图里直接填写自定义 `W=900`、`H=900` 后保存，曾回写为新地址但仍显示 `800 X 800`。遇到 800 方形图时，优先用 `方形主图 (1000 x 1000)` 预设。
- 点击 `保存` 只会展开菜单；必须继续点 `保存并应用`，不要点 `保存至图片空间` 或 `保存至本地`。

## 补选细节图

当某颜色细节图显示 `【1 / 11 图片】` 且有 `至少选择2张细节图` 红字时：

1. 点击该颜色行细节图列的 `选择图片`。
2. 在下拉菜单中点击 `引用采集图片`。
3. 弹窗标题为 `引用采集图片`，每张图上方有 `选择图片` 复选框，右下角有 `选择` 按钮。
4. 不要选择自然尺寸低于 900 的图片。先读取或检查弹窗中图片的自然尺寸，选择边长在 `900px-2200px` 且比例合规的图片。
5. 本次验证可用的合规补充图：
   - 源地址包含 `O1CN01HW3AOM1hhZgfoO6OL_!!2216984634309-0-cib.jpg`
   - 自然尺寸 `1440 x 1440`
   - 弹窗内部下滚后可见，位于可见区域底部第三列附近。
6. 勾选该图对应的 `选择图片` 复选框。
7. 点击弹窗右下角 `选择`。
8. 回到变种图片表格，确认该颜色细节图变为 `【2 / 11 图片】`，并且尺寸文本包含两张合规图，例如 `1000 X 1000 1440 X 1440`。

已验证结果：
- Blue 行补选 1440 x 1440 后，细节图显示 `【2 / 11 图片】 1000 X 1000 1440 X 1440`。
- Black 行补选同一张 1440 x 1440 后，细节图显示 `【2 / 11 图片】 1000 X 1000 1440 X 1440`。

## 保存与复查

1. 保存前，只在变种图片表格内检查红字，不要用全页文本判断。页面其它区块可能仍包含无关红字。
2. 变种图片表格内不应包含以下文本：
   - `至少选择2张细节图`
   - `细节图支持上传宽高比例`
   - `900 x 900 至 2200 x 2200`
3. 本次成功保存前的表格状态：
   - Blue: `【2 / 11 图片】 1000 X 1000 1440 X 1440`，方形图 `1000 X 1000`，色块图 `80 X 80`
   - Black: `【2 / 11 图片】 1000 X 1000 1440 X 1440`，方形图 `900 X 900`，色块图 `80 X 80`
4. 用户要求最终保存时，滚动到页面顶部或底部，点击普通 `保存` 按钮。
5. 避免误点：
   - 不点 `保存并移入待发布`
   - 不点 `发布`
6. 点击普通 `保存` 后，再滚回 `变种图片` 表格，确认表格内仍无上述红色报错文案。

## 操作注意

- `小秘美图` 菜单项在 DOM 中可能有多个隐藏同名文本。若文本 locator 命中隐藏模板，改用当前可见菜单坐标或限定可见菜单项。
- 表头 `编辑` 下拉的 `批量编辑` 可能先打开选择图片弹窗；本次曾出现选择全部后点 `确定` 未继续进入编辑器的情况。遇到这种卡点时，改用单张缩略图蓝色魔棒。
- 每一步点击后做局部状态检查：菜单是否展开、新标签是否打开、编辑器是否关闭、表格尺寸和数量是否更新。
- 最终报告必须说明处理了哪些颜色、哪些列、是否进入 `/web/newImageEditor`、是否点过图片编辑器 `保存并应用`、是否点过商品页普通 `保存`、保存后变种图区块是否仍有红色报错。
