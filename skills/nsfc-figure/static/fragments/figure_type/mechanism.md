# 机制假说图设计指引

## 设计原则
- 实线=已知通路/机制（有文献支撑）
- 虚线=本课题假说（待验证）
- "?"=待验证的关键环节
- 核心分子用暖色（红/橙），上下游用冷色（蓝/绿）

## 标准布局

```
[上游刺激/病理条件]
       ↓
 ┌──────────┐
 │ 核心分子A │ ← 暖色突出
 └────┬─────┘
      ↓ (虚线=假说)
 ┌──────────┐    ┌──────────┐
 │  通路B    │─?─→│ 效应分子C │
 └────┬─────┘    └────┬─────┘
      ↓                 ↓
 ┌─────────────────────────┐
 │      细胞表型D           │
 └──────────┬──────────────┘
            ↓
 ┌─────────────────────────┐
 │      疾病结局E           │
 └─────────────────────────┘

图例: ── 已知   - - - 假说   ? 待验证
```

## 输出内容

1. 文字描述版（核心逻辑+箭头关系）
2. 绘图工具建议（PPT/BioRender/Adobe Illustrator）
3. 配色方案（具体色号建议）
4. 排版建议（字号/加粗/箭头粗细）
