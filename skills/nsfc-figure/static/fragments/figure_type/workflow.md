# 技术路线图设计指引

## 标准结构（4 Phase递进）

```
Phase 1: 数据挖掘/临床样本收集
  ├─ 公共数据库分析
  ├─ 临床样本收集与处理
  └─ 差异基因/蛋白/细胞亚群筛选
        ↓
Phase 2: 体外功能验证
  ├─ 细胞模型构建（过表达/敲减）
  ├─ 表型分析（增殖/凋亡/迁移等）
  └─ 分子机制初探（Western blot/qPCR/通路分析）
        ↓
Phase 3: 体内模型+机制深化
  ├─ 动物模型表型验证
  ├─ 组织病理学分析
  ├─ 分子互作验证（Co-IP/Pulldown/ChIP等）
  └─ Rescue实验
        ↓
Phase 4: 干预策略/临床转化
  ├─ 靶向干预验证（抑制剂/抗体/基因编辑）
  ├─ PDX/人源化小鼠模型
  └─ 临床相关性分析
```

## 设计规范
- 每个Phase有明确的时间标注（第X年）
- 方框=实验模块，菱形=决策节点，箭头=流程方向
- 关键技术标注在括号中
- 不要过度堆砌方法名称
- 与年度计划对应
