# NSFC Figure — Default Stance & Figure Taxonomy

## Default Stance

1. **图表是论证工具，不是装饰品**：每张图必须在正文中被引用和讨论。
2. **30秒原则**：核心机制图应让评审专家在30秒内看懂本研究的核心逻辑。
3. **实线=已知，虚线=假说**：机制图中的虚实线区分是中标标书的标配。
4. **一致性优先于美观**：同一份标书中的配色、字体、箭头风格必须统一。
5. **预实验图必须真实**：不能生成虚假的实验数据图。

## Figure Taxonomy

### 1. 机制假说图 (Mechanism Hypothesis Diagram)
- 用途：总结全文科学假说的核心逻辑
- 出现位置：立项依据末尾 或 研究方案开头（中标标书中57%放立项依据末，43%放研究方案前）
- 关键元素：核心分子（暖色）+ 上下游信号（冷色）+ 虚线（待验证）+ "?"标注
- 对标中标标书：100%含有此类图

### 2. 信号通路图 (Signaling Pathway Diagram)
- 用途：展示已知通路 + 本研究拟探索部分
- 出现位置：立项依据中段，引入核心分子/通路时
- 关键元素：已知通路（实线）+ 探索部分（虚线）
- 对标中标标书：90%含有此类图

### 3. 技术路线图 (Technical Roadmap)
- 用途：展示研究步骤和流程
- 出现位置：研究方案开头
- 关键元素：阶段划分（Phase 1-4）+ 箭头 + 决策节点
- 对标中标标书：85%含有此类图

### 4. 预实验数据图 (Preliminary Data Figures)
- 用途：展示前期研究基础的关键实验结果
- 出现位置：**研究基础中**（⚠️ 不放立项依据，立项依据只放机制/通路示意图）
- 关键元素：WB条带/统计图/显微照片/生信分析图
- 对标中标标书：100%含有此类图，平均8-12项
- ⚠️ **【强制】必须按论证逻辑拆分为多张独立图（Figure S1, S2, S3...），每张图独立说明一个论证问题，非1张大组合图**
- ⚠️ 每张图必须有：独立图标题 + panel说明(A/B/C/D) + n值 + 统计方法 + P值标注

### 5. 生物信息学分析图 (Bioinformatics Figures)
- 用途：展示公共数据挖掘结果
- 出现位置：立项依据中 或 研究方案数据挖掘部分
- 常见类型：热图、火山图、GSEA、GO/KEGG富集、韦恩图、相关性分析图
- 对标中标标书：80%含有此类图

### 6. 临床相关性图 (Clinical Correlation Figures)
- 用途：展示基因/蛋白表达与临床参数的关系
- 出现位置：研究方案临床验证部分 或 研究基础
- 常见类型：生存曲线（Kaplan-Meier）、ROC曲线、表达相关性热图
- 对标中标标书：45%含有此类图
