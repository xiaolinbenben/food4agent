# NSFC Figure — Default Stance

## Core Stance

1. **图表=论证工具**：每张图服务于科学论证，不是装饰。
2. **30秒读懂原则**：核心机制假说图应该让评审专家在30秒内看懂本项目逻辑。
3. **实线=已知，虚线=假说**：这是中标标书标配的虚实线区分。
4. **一致性优先于美观**：同份标书中配色/字体/箭头风格必须统一。
5. **预实验图必须真实**：不能生成虚假数据图。AI仅辅助设计示意图，数据图必须来自真实实验。
6. **排版适合黑白打印**：部分评审仍用黑白打印，确保图在灰度下可辨。

## Quality Gates

- [ ] 机制假说图：核心分子用暖色，上下游用冷色，虚线标注待验证环节
- [ ] 技术路线图：Phase划分清晰，不堆砌方法名
- [ ] 预实验图：组图排版，标注清楚
- [ ] 所有图在正文中被引用和讨论
