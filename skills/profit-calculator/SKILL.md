# Profit Calculator 💰

> 精确计算电商产品的盈利能力，优化定价策略

专业的电商利润分析工具，帮助您计算ROI、盈亏平衡点、边际贡献，并生成详细的盈利预测报告。

---

## 🎯 核心功能

### 1. ROI 计算
```
投资回报率 = (净利润 / 总投资成本) × 100%

考虑因素:
├─ 产品成本
├─ 营销费用
├─ 运营成本
├─ 平台费用
└─ 时间价值
```

### 2. 盈亏平衡分析
```
盈亏平衡点 = 固定成本 / (单价 - 变动成本)

关键指标:
├─ 销售数量平衡点
├─ 销售收入平衡点
├─ 时间平衡点
└─ 安全边际
```

### 3. 边际贡献
```
边际贡献 = 销售价格 - 变动成本

应用场景:
├─ 产品组合优化
├─ 促销活动评估
├─ 资源分配决策
└─ 竞争策略制定
```

## 🧮 计算模型

### 完整利润公式
```python
净利润 = (销售价格 × 销量) 
         - (产品成本 × 销量)
         - 物流成本
         - 平台佣金
         - 营销费用
         - 固定成本
         - 退货损失
```

### ROI 计算
```python
总投资 = 产品成本 + 库存成本 + 营销成本 + 设备成本
年净利润 = 月净利润 × 12
ROI = (年净利润 / 总投资) × 100%
```

### 盈亏平衡点
```python
单位边际贡献 = 销售价格 - 单位变动成本
盈亏平衡销量 = 固定成本 / 单位边际贡献
盈亏平衡收入 = 盈亏平衡销量 × 销售价格
```
