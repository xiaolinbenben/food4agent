# Dianxiaomi SHEIN Size Chart Editing

Use this skill only for the size-chart modal on the Dianxiaomi SHEIN edit page.

This skill does not own source URL, title, description, price, image upload, normal save, or move-to-pending actions. It owns only:

- finding usable size evidence from local source files
- opening the size-chart modal
- filling only the required current-modal fields
- applying the modal
- reporting whether values were source-backed or estimated

## Prerequisites

- You must use `control-chrome` to connect to the user's real Chrome.
- Assume Chrome is logged into an operable Dianxiaomi account by default. If not logged in, the account is wrong, or permissions are insufficient, stop and let the user handle it.
- Prefer local source files in this order:
  - `product-context.json`
  - `raw-product.json`
- Handle only the size-chart modal entered from the current SHEIN edit page.
- Do not click the product page's save, save-and-move, or publish buttons inside this skill unless the caller explicitly included that action.

## Page Contract

Use the current verified page contract below. No external AGENTS page-contract file is present in this workspace.

Important current cue:

- size-chart form item class: `.skuAttrSizeChart`
- visible entry text: `尺码表`, `编辑尺码表`, or `Size Chart`

Treat only the currently visible modal as actionable. Ignore hidden duplicate DOM left behind after modal close.

## Source-Evidence Workflow

1. Confirm that the current Dianxiaomi edit page matches the local source product by checking source URL, product title, offer id, or item number.
2. Prefer size-chart image URLs from local source files.
3. First reuse the image candidate artifacts that were already produced by `dianxiaomi-shein-image-generate`:
   - `data/<offerId>/image/candidates/manifest.json`
   - `data/<offerId>/image/candidates/contact-sheet.jpg`
4. Only if those candidate artifacts are missing, incomplete, or unusable, prepare size-chart candidates with:

```powershell
.\.codex\skills\dianxiaomi-shein-size-chart\scripts\prepare_size_chart_candidates.ps1 `
  -RawProductJson "data\<offerId>\raw-product.json"
```

5. Inspect the reusable or generated contact sheet, then open the exact candidate image files needed for final reading.
6. If a reliable source size chart exists and matches the current product, fill values from that source chart.
7. If no reliable source size chart exists, use common-sense completion for the current modal's required columns only and report that those values were estimated.

## Fill Rules

- Fill by actual size labels, not by row order.
- Fill only sizes that actually exist on the current SHEIN edit page.
- Do not add extra sizes from source images into Dianxiaomi unless the user explicitly asks.
- Fill only columns currently marked required in the modal.
- In the current modal, required columns are marked by a child element with class `required` inside the table header. Do not rely on the row input's HTML `required` attribute; it can be false even for required columns.
- Do not fill optional columns unless the user explicitly asks in the current turn.
- If the current modal has a saved template selector, use a saved template only when it clearly matches the current category and size set.
- If the source image is blurry, compressed, unreadable, or the unit is unclear, stop and ask the user.

## Mapping Rules

- `Waist` maps only to `Waist`.
- `Hip` maps only to `Hip`.
- `Length` or pants length maps only to a matching length field.
- Do not treat pants length as `Inseam` unless the source explicitly says `Inseam`.
- If the modal requires a field that is absent from the source image, estimate only that required field and report it.
- If the current SHEIN product has a size that the source image does not provide, do not infer a missing source size beyond the allowed required-field estimation rule. Report it.

## Apply Rules

1. Open `编辑尺码表`.
2. Read the currently required columns and current size labels.
3. Fill only the required fields.
4. Click the modal's `确定`.
5. After the modal closes, check only for immediate error messages. Do not reopen the size chart just to read values back unless the user explicitly asks for verification.

## Output

Return:

- local source file path used
- whether source image evidence was used or estimated values were used
- whether image candidates were reused from `image/candidates` or regenerated by the size-chart script
- which candidate image URLs or files were used
- which required fields were filled
- which fields were estimated
- whether the modal applied cleanly
