# Rerank结果重排（v4.2.0）

## 迭代检索Rerank核心变化

- **多轮结果合并**: 合并Round1/2/3结果，按轮次权重处理
- **采纳建议评分**: 输出明确采纳建议（强烈推荐/推荐/可选/谨慎采纳）
- **缺口填补标记**: 标记结果填补的信息缺口类型

## Rerank执行步骤

### Step 1: 去重

```javascript
// 去重规则
- 相同URL直接合并
- 相同标题（相似度>0.9）合并，保留权重高的来源
- 同一站点多个结果，保留权重最高的2个
```

### Step 2: 加权排序

```javascript
// 排序公式
score = source_weight * relevance_factor

// 相关性因子
- 标题完全匹配查询词       → relevance_factor = 1.0
- 标题包含查询词           → relevance_factor = 0.8
- 摘要包含查询词           → relevance_factor = 0.6
- 仅URL包含查询词          → relevance_factor = 0.4
```

### Step 3: 时效性修正

```javascript
// 新闻类查询时效性加成
if (query_type == "news") {
  // 24小时内 +0.2
  // 7天内 +0.1
  // 30天内 +0.05
  // 30天以上 -0.1
}
```

### Step 4: 相关性过滤

```javascript
// 过滤规则
- 移除score < 0.3的结果
- 移除明显不相关的内容（广告、推广）
- 移除无法访问的链接
```

### Step 5: 数量限制

```javascript
// 精简规则
- 默认保留Top10结果
- 新闻类保留Top15
- 学术类保留Top5
```

## 多维度评分体系（v2.3新增）

| 维度 | 权重 | 评分规则 |
|------|------|----------|
| **相关性** | 35% | 标题匹配度 + 语义匹配度 |
| **权威性** | 25% | 来源权重（政务1.0→社交0.6） |
| **时效性** | 20% | 发布时间衰减（24h内+0.2，30天外-0.1） |
| **完整性** | 15% | 信息覆盖度（是否覆盖核心需求） |
| **新颖性** | 5% | 多轮检索中的新发现价值 |

### 综合评分公式

```javascript
score = (
  relevanceScore * 0.35 +
  authorityScore * 0.25 +
  timelinessScore * 0.20 +
  completenessScore * 0.15 +
  noveltyScore * 0.05
) * roundWeight

// 轮次权重（后轮结果权重略低）
roundWeight = { round1: 1.0, round2: 0.9, round3: 0.8 }
```

## 采纳建议分级

| 综合评分 | 采纳建议 | 适用场景 |
|----------|----------|----------|
| ≥ 0.85 | **强烈推荐** | 决策依据、权威佐证 |
| 0.70-0.84 | **推荐** | 数据参考、专业分析 |
| 0.55-0.69 | **可选** | 补充视角、案例参考 |
| 0.40-0.54 | **谨慎采纳** | 需交叉验证 |
| < 0.40 | **不推荐** | 过滤或忽略 |

## 特殊场景处理

| 场景 | 处理规则 |
|------|----------|
| 多引擎并行 | 按权重合并，同一来源去重 |
| 无结果 | 切换备用引擎重试 |
| 结果质量低 | 放宽关键词，切换引擎 |
| 官方信息优先 | 官方来源权重+0.2 |
