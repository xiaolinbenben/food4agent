# 交叉验证机制 v4.2.0

> **核心原则**: 关键信息必须多源验证，冲突必须标注

---

## 触发条件

```
IF 查询涉及以下任一类型 → 必须执行交叉验证:
  → 版本号/发布日期
  → 数据指标（价格/利率/GDP/人口等）
  → 政策法规（生效时间/适用范围/具体条款）
  → 医学健康（症状/用药/治疗方案）
  → 法律判例（判决结果/赔偿标准/法律条文）
  → 技术规格（API参数/配置项/兼容性）

IF 查询为简单事实且仅1个来源 → 可不验证，但标注"❌无法验证"
```

---

## 验证流程

### Step 1: 关键信息提取

```
从搜索结果中提取可验证的关键信息:
  → 版本号: "v5.2.1", "JDK 25"
  → 日期: "2026-03-15", "2025年9月"
  → 数值: "利率4.35%", "GDP增长5.2%"
  → 名称: "具体政策名/法律名/药品名"
  → 布尔: "已发布/未发布", "支持/不支持"
```

### Step 2: 多来源对比

```
统计各来源对同一关键信息的表述:
  → 来源A: "发布于2026-03-15" (🏢官方)
  → 来源B: "发布于2026-03-15" (📰权威媒体)
  → 来源C: "发布于2026-03-14" (👥技术社区)

计算一致率:
  → 完全一致: 2/3 = 67%
  → 近似一致(±1天): 3/3 = 100%
```

### Step 3: 冲突检测

```
IF 同一关键信息在不同来源中表述不同:
  → 判定为信息冲突
  → 按来源权威性排序:
    🏢官方 > 📰权威媒体 > 👥技术社区 > 📝个人博客
  → IF 同级来源冲突 → 标注"需人工确认"
```

### Step 4: 验证结论输出

```
✅ 确认真实
  条件: ≥2个来源一致，且至少1个🏢官方或📰权威媒体
  输出: "✅ 确认真实 (3个来源一致, 可信度95%)"

⚠️ 存在冲突
  条件: 来源间存在不一致
  输出: "⚠️ 存在冲突 (来源A说X, 来源B说Y, 建议以官方为准)"

❌ 无法验证
  条件: 仅1个来源，或所有来源均为📝个人博客/❓未验证
  输出: "❌ 无法验证 (仅单一来源, 建议查找官方确认)"
```

---

## 冲突解决策略

### 按权威性排序

```
优先级 (从高到低):
1. 🏢 官方来源 (权重1.0)
   → 政府网站、官方文档、厂商公告
2. 📰 权威媒体 (权重0.85)
   → 财新、央视、新华社、人民日报
3. 👥 技术社区 (权重0.7)
   → CSDN、掘金、知乎高赞回答
4. 📝 个人博客 (权重0.5)
   → 个人站点、知乎专栏、微信公众号
```

### 冲突类型与处理

| 冲突类型 | 示例 | 处理策略 |
|----------|------|----------|
| 数值冲突 | A说"4.35%", B说"4.25%" | 采信官方，标注差异 |
| 日期冲突 | A说"3月15日", B说"3月14日" | 采信官方，标注"±1天" |
| 布尔冲突 | A说"已发布", B说"未发布" | 标注"需人工确认" |
| 名称冲突 | A说"政策X", B说"政策Y" | 可能指不同政策，分别列出 |

## 可信度计算

```
credibility = (
  source_count_score * 0.3 +     来源数量分
  authority_score * 0.4 +         权威性分
  consistency_score * 0.3         一致性分
)

source_count_score:
  1个来源 → 0.3
  2个来源 → 0.6
  3个来源 → 0.8
  4+个来源 → 1.0

authority_score:
  全部官方 → 1.0
  官方+权威 → 0.85
  权威+社区 → 0.7
  全部社区 → 0.5
  全部个人 → 0.3

consistency_score:
  100%一致 → 1.0
  90%+一致 → 0.8
  70%+一致 → 0.6
  <70%一致 → 0.3
```

## 输出格式

```markdown
### 🔍 交叉验证

**关键信息**: [提取的关键事实]

| 信息项 | 来源A (🏢官方) | 来源B (📰权威) | 来源C (👥社区) |
|--------|----------------|----------------|----------------|
| 版本号 | v5.2.1 | v5.2.1 | v5.2.0 |
| 发布日期 | 2026-03-15 | 2026-03-15 | 2026-03-14 |

**验证结论**: ✅ 确认真实 (2/3来源一致, 可信度85%)
**冲突说明**: 版本号存在微小差异，以官方为准

**来源统计**: 3个 (1个官方 + 1个权威 + 1个社区)
**一致性**: 67%完全一致 / 100%近似一致(±1版本)
```

## 验证示例

### 示例1: 技术版本验证

```
查询: "React 19正式版发布时间"
来源A (🏢react.dev): "2024年12月5日"
来源B (📰InfoQ): "2024年12月5日"
来源C (👥掘金): "2024年12月"

验证结论: ✅ 确认真实 (3个来源一致, 可信度95%)
```

### 示例2: 数据冲突

```
查询: "中国2025年GDP增速"
来源A (🏢国家统计局): "5.2%"
来源B (📰财新): "5.1%"
来源C (👥雪球): "5.3%"

验证结论: ⚠️ 存在冲突 (数值差异0.1-0.2%, 以国家统计局为准)
```

### 示例3: 医学信息验证

```
查询: "布洛芬成人每日最大剂量"
来源A (🏢用药助手): "1200mg"
来源B (🏥好大夫): "1200mg"
来源C (👥百度知道): "800mg"

验证结论: ✅ 确认真实 (2/3权威来源一致1200mg, 可信度90%)
⚠️ 免责声明: 以上信息仅供参考，不构成医疗建议。
```
