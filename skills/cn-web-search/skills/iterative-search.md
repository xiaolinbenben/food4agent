# 迭代检索流程（检索-推理-再检索）

## 核心流程

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│  第1轮检索  │ ──► │  信息缺口分析 │ ──► │  子问题拆分 │
│  TOP10-20   │     │  模型推理判断 │     │  生成新查询 │
└─────────────┘     └──────────────┘     └─────────────┘
                                                │
                    ┌─────────────────────────────┘
                    ▼
             ┌─────────────┐     ┌──────────────┐
             │  第2轮检索  │ ──► │  结果汇总    │
             │  补充检索   │     │  Rerank输出  │
             └─────────────┘     └──────────────┘
```

---

## 第一阶段：意图解析与多轮查询生成

### 意图分类

| 意图类型 | 特征 | 检索轮数 |
|----------|------|----------|
| **简单事实** | 单点信息、明确答案 | 1轮 |
| **复杂研究** | 多维度、需对比分析 | 2-3轮 |
| **时效热点** | 新闻、政策、事件 | 2轮（补充时间线） |
| **技术问题** | 代码、原理、方案 | 2轮（教程+原理） |
| **决策支持** | 购买、投资、选择 | 3轮（数据+观点+评测） |

### 多轮查询生成策略

```javascript
// 意图解析示例
用户查询: "2026年新能源汽车补贴政策对购车影响"

// 自动拆分为多轮查询:
Round1: ["新能源汽车补贴政策2026", "2026年新能源购车补贴"]
Round2: ["补贴政策对购车成本影响", "新能源车补贴取消影响"]
Round3: ["新能源车购车建议2026", "补贴政策下购车时机"]
```

## 第二阶段：检索执行

### TOP10-20检索规则

| 轮次 | 目标 | 引擎选择 |
|------|------|----------|
| **第1轮** | 广泛召回 | P0引擎 + 通用引擎（百度/必应） |
| **第2轮** | 精准补充 | P1引擎 + 垂直引擎 |
| **第3轮** | 深度验证 | 官方来源 + 权威媒体 |

### 并行检索配置

```javascript
// 第1轮：广泛召回
const round1 = parallelSearch([
  { engine: "百度", query: originalQuery },
  { engine: "必应中文", query: originalQuery },
  { engine: "P0_Vertical", query: originalQuery }
], { maxResults: 20 });

// 第2轮：精准补充（基于缺口分析）
const round2 = parallelSearch([
  { engine: "垂直引擎1", query: subQuery1 },
  { engine: "垂直引擎2", query: subQuery2 }
], { maxResults: 10 });
```

## 第三阶段：信息缺口分析

### 模型推理判断规则

```markdown
## 信息缺口检测维度

1. **完整性缺口**: 关键信息未覆盖（如数据缺失、时间缺失）
2. **权威性缺口**: 缺少官方/权威来源佐证
3. **时效性缺口**: 信息陈旧，需最新更新
4. **多样性缺口**: 观点单一，缺少对比视角
5. **深度缺口**: 原理/背景解释不足

## 判断流程

1. 分析Round1结果，识别缺口类型
2. 针对缺口生成补充查询词
3. 选择补充检索引擎
4. 执行Round2检索
```

### 缺口分析与子问题生成示例

```javascript
// 分析示例
Round1结果分析: {
  covered: ["补贴金额", "政策时间", "适用车型"],
  gaps: {
    "完整性": "缺少具体补贴计算公式",
    "权威性": "缺少官方政策原文",
    "多样性": "缺少消费者实际获益案例"
  }
}

// 生成子问题
subQueries: [
  "新能源汽车补贴计算方法官方文件",
  "新能源补贴政策消费者案例",
  "2026购车补贴实际节省金额计算"
]
```

## 第四阶段：迭代控制

### 轮数控制规则

| 规则 | 配置 |
|------|------|
| **最大轮数** | 3轮 |
| **终止条件** | 信息缺口已填补 OR 连续2轮无新有效结果 |
| **轮间隔** | 模型分析时间 ≤2秒 |
| **单轮超时** | 搜索请求 ≤3秒 |

### 迭代终止判断

```javascript
// 终止条件判断
function shouldStop(round, previousResults, currentResults) {
  // 条件1: 已达最大轮数
  if (round >= 3) return true;

  // 条件2: 缺口已填补（模型判断）
  if (gapsFilled(currentResults)) return true;

  // 条件3: 无新增有效结果
  const newValidResults = dedup(currentResults, previousResults);
  if (newValidResults.length < 3) return true;

  return false;
}
```

## 第五阶段：Rerank评分机制（增强版）

### 多维度评分体系

| 维度 | 权重 | 评分规则 |
|------|------|----------|
| **相关性** | 35% | 标题匹配度 + 语义匹配度 |
| **权威性** | 25% | 来源权重（政务1.0→社交0.6） |
| **时效性** | 20% | 发布时间衰减（24h内+0.2，30天外-0.1） |
| **完整性** | 15% | 信息覆盖度（是否覆盖核心需求） |
| **新颖性** | 5% | 多轮检索中的新发现价值 |

### Rerank评分公式

```javascript
// 综合评分公式
score = (
  relevanceScore * 0.35 +
  authorityScore * 0.25 +
  timelinessScore * 0.20 +
  completenessScore * 0.15 +
  noveltyScore * 0.05
) * roundWeight

// 轮次权重（后轮结果权重略低）
roundWeight = {
  round1: 1.0,
  round2: 0.9,
  round3: 0.8
}
```

```markdown

| 排名 | 来源 | 综合评分 | 相关性 | 权威性 | 时效性 | 采纳建议 |
|------|------|----------|--------|--------|--------|----------|
| 1 | 政府官网 | 0.92 | ★★★★★ | ★★★★★ | ★★★★☆ | **强烈推荐** - 官方权威 |
| 2 | 人民日报 | 0.88 | ★★★★★ | ★★★★★ | ★★★★★ | **强烈推荐** - 权威时效 |
| 3 | 东方财富 | 0.75 | ★★★★☆ | ★★★★☆ | ★★★☆☆ | **推荐** - 数据详实 |
| 4 | 知乎分析 | 0.62 | ★★★☆☆ | ★★★☆☆ | ★★★☆☆ | **可选** - 补充视角 |
| 5 | 小红书 | 0.48 | ★★☆☆☆ | ★★☆☆☆ | ★★★☆☆ | **谨慎采纳** - 需验证 |

### 结果分类采纳建议

- **决策依据**: 优先采纳排名1-2（官方权威）
- **数据参考**: 采纳排名3（专业平台）
- **补充视角**: 可参考排名4-5（社区观点）
- **需验证**: 排名5以下需交叉验证
```

## 与Agent Browser协同

### 复杂页面处理

```javascript
// 当WebFetch无法获取内容时，切换Agent Browser
if (webFetchFailed || dynamicContent) {
  agent_browser.launch({
    url: targetUrl,
    action: "extract_content",
    fallback: true
  });
}
```

### 异常处理流程

| 异常类型 | 处理策略 |
|----------|----------|
| **引擎无响应** | 切换备用引擎，记录异常 |
| **内容抓取失败** | 启用Agent Browser |
| **结果重复率高** | 放宽查询词，扩大引擎范围 |
| **信息缺口未填补** | 提示用户补充查询方向 |
