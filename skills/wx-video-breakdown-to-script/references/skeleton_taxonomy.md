# 4 套视频骨架 + 字幕色规 · 通用规范

> 这套分类是基于"广东综评升学规划"赛道拉片提炼的，但骨架本身是通用的——
> 任何「口播 + B-roll」类垂直内容（财经/法律/教育/医疗科普）都能套用。

---

## 骨架对应表（选题来了先看这个）

| 选题类型 | 推荐骨架 | 目标时长 | 示例 |
|---|---|---|---|
| 面试/笔试/初审/真题拆解 | **A 干货拆解** | 60-90 秒 | "中大综评面试 7 分钟换 20-40 分降分" |
| 某院校政策解读 | **A 干货拆解** | 80-120 秒 | "2026 BNBU 简章三大调整" |
| 学员真实案例 / 学长学姐采访 | **B 学员采访** | 90-120 秒 | "BNBU 224 分学员专访" |
| 实地走访某校园 | **C 探校片** | 120-180 秒 | "飞学长二刷港城莞" |
| 大盘对比 / 多院校扫盘 / 误区科普 | **D 深聊大盘** | 150-180 秒 | "6 条降分路径一次说清" |

## 骨架 A · 干货拆解片

**适用**：面试 / 笔试 / 初审 / 简章解读 / 数据解读类
**核心**：信息密度优先，60-90 秒讲完一个完整知识点

### 结构模板（按秒）

| 段落 | 时间 | 内容 |
|---|---|---|
| 钩子板 | 0-3s | 满屏大字标题 + 副标问题/承诺 + 1-3 个数字锚点 |
| 痛点数据 | 3-8s | B-roll + 大字字幕（"X% 直接决定 X"） |
| 价值公式 | 8-18s | 真人 + 大字花字（"降分 X 分 = 用 X 的分数捡 X"） |
| 硬干货板 | 18-35s | 风景 B-roll + 信息板（流程/时长/人数） |
| 分类清单 | 35-55s | 风景 B-roll + 4 类列表（每类一句话注解） |
| 服务引导 | 55-68s | 真人 + 服务清单（自然带出服务） |
| 软 CTA 收尾 | 68-90s | 真人定格 + 大字金句（"现在准备还来得及"） |

### 视听特征
- **真人:B-roll ≈ 4:6**
- 顶部红框标题板**全程不消失**（品牌锚点）
- 数字字幕用黄色 + 加粗 + 1.5 倍字号

---

## 骨架 B · 学员采访片（最低成本起量推荐）

**适用**：学员真实案例 / 学长学姐采访
**核心**：故事钩子优先，**单机位一镜到底**

### 结构模板

| 段落 | 时间 | 内容 |
|---|---|---|
| 满屏钩子板 | 0-2s | 被采访者坐姿 + 大字标题 + 三段式数据墙 |
| 切换标题板 | 2-5s | 顶部双层常驻标题板（主标+悬念副标） |
| Q1 背景 | 5-25s | 真人对话（高考/学校/分数） |
| Q2 选综评 | 25-50s | 真人对话（为什么选这条路） |
| Q3 关键时刻 | 50-75s | 真人对话（面试/校测/报名经历） |
| Q4 入学体验 | 75-100s | 真人对话（最大感受 + 具体细节） |
| Q5 建议 | 100-115s | 真人对话（给学弟学妹一句话） |
| 温情收尾 | 115-120s | 同机位 + 飞学长画外致谢 |

### 视听特征
- **整片单机位无切镜**（核心规则！）
- 字幕跟随逐字稿，关键数字加黄色加粗
- BGM 极轻氛围（钢琴单音）不抢人声
- **不强 CTA**，靠顶部标题板的悬念承担转发心智

### 5 问模板（提前 24 小时发被采访者熟悉）

1. 介绍下你的高考分数 + 高中 + 选科
2. 你 [分数] 已经能上 [对照院校]，为什么还要走综评？/ 当时为什么纠结 [对比方案]？
3. 当时申请综评的过程、面试经历，有没有印象深的瞬间？
4. 入学之后最大的感受 + 一个具体细节
5. 给后面的学弟学妹一句话建议

## 骨架 C · 探校片（B-roll 占 60%）

**适用**：实地走访某校园 / 校区对比 / 校园软实力呈现
**核心**：画面承载内容权重 > 真人口播

### 结构模板

| 段落 | 时间 | 内容 |
|---|---|---|
| IP 钩子板 | 0-3s | 真人@校门 + 综艺花字 logo（"XX 探校" + 装饰元素）+ 三段式数据钩子 |
| 校园 B-roll | 3-30s | 大量校园航拍 + 走读 + 标志性建筑 |
| 真人节点 | 30-90s | 关键卖点用真人出镜强调，背景必选标志物 |
| 软实力 B-roll | 90-130s | 宿舍/食堂/图书馆/教学楼，回答家长心智问题 |
| 性价比+综评钩子 | 130-160s | B-roll + 大字花字（"你 X 分 X 专业 → 通过综评 X"） |
| IP 软广收尾 | 160-180s | 真人@标志性背景 + 下集预告 |

### 视听特征
- **B-roll 占 60%+**
- 专属"XX 探校"系列花字 logo（建立 IP）
- BGM 选明快卡点（BPM 110）

## 骨架 D · 深聊大盘片

**适用**：大盘对比 / 多院校扫盘 / 政策梳理 / 误区科普
**核心**：单机位"深聊"调性，靠**章节大字板**做节奏

### 结构模板

| 段落 | 时间 | 内容 |
|---|---|---|
| **裸帧钩子** | 0-1s | 真人坐校园石凳 **无标题板**，只有底部一行大字 |
| 系列 IP 角标 | 1s+ | 左上角小角标（"XX 说 XX"）+ 副标条延续钩子 |
| 痛点共情 | 4-25s | 真人 + 字幕（"很多家长 X / 但绝不应该是 X"） |
| 章节大字板 ×N | 每章 25-35s | 大字章节板（背景品牌红、白字大号"第 X 条 + 标题"） |
| 直白 CTA 收尾 | 最后 8s | 真人 + 直白 CTA（"评论区留 X"） |

### 视听特征
- **单机位**坐着深聊，深色服装稳重感
- 无 B-roll，靠"章节板大字"做节奏
- BGM 沉稳钢琴+大提琴 BPM 75
- CTA **必须显性**（"评论区留 X"），配套私信关键词

## 字幕色彩规范（铁律）

| 颜色 | 色值 | 用途 | 字号示意 |
|---|---|---|---|
| 🟡 黄 | `#E89B1A` | **数字**（分数 / 名额 / 时长 / 降分） | 80px 加粗 |
| 🔴 红 | `#C00000` | **结论**（强调 / 反转 / 价值判断） | 72px 加粗 |
| ⚪ 白 | `#FFFFFF` | **旁白**（普通信息 / 串场逐字稿） | 56px 常规 |
| 🟥 品牌红 | `#D33A2C` | 顶部标题板红框 / 章节大字板背景 | — |

**口诀：数字必黄、结论必红、其他必白。** 颜色用错就要打回重剪。

字幕描边统一黑色：
- 黄字 + 红字描边 4px
- 白字描边 3px

字幕位置：
- 顶部红框标题板 = 顶部 5%
- 浮动大字 = 中下 30%
- 逐字稿 = 底部 12%

## BGM 库参考

| 骨架 | BGM 风格 | BPM | 参考曲目 |
|---|---|---|---|
| A 干货 | 轻钢琴+弦乐 | 90 | "Calm Piano - Morning" |
| B 采访 | 极轻氛围 钢琴单音 | 70 | "Soft Memory" |
| C 探校 | 明快卡点 | 110 | "Travel Vlog Theme" |
| D 深聊 | 沉稳钢琴+大提琴 | 75 | "Reflection" |

音量控制：
- BGM 默认 -22dB（不抢人声）
- 人声 -6dB
- 关键转场加 swoosh 音效（标题板出现时、章节切换时）

## 导出参数（所有视频统一）

- 分辨率 1080×1920 竖屏
- 30 fps（不要 60）
- H.264 编码
- 码率 A/B/D 8-12 Mbps，C 探校 12-15 Mbps（B-roll 多）
- 音频 AAC 192 kbps 立体声
