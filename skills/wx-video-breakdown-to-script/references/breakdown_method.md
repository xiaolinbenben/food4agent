# 拉片方法论 · 5 大维度 + 抽帧策略

## 为什么要按维度拉片，而不是"看个感觉"

短视频的成功是可以拆解的——前 3 秒怎么钩住、中段信息密度怎么排、收尾怎么 CTA，这些都是**可复现的工艺**，不是玄学。

**目标**：把对标账号的"内容公式"拆出来，让你的团队按这个公式生产 N 条同款。

---

## 拉片 5 大维度

### 维度 1：基础信息
- 时长
- 发布时间
- 点赞/评论/转发量（用户人工补）
- 账号定位

### 维度 2：钩子层（前 3 秒）
**最重要的部分。短视频留存的 80% 决定在前 3 秒。**

记录：
- **钩子类型**（5 选 1）：
  - A. 数字承诺型（"7 分钟换 20-40 分降分"）
  - B. 数据悬念型（"540 分和 580 分进了同一所大学?"）
  - C. 价格反差型（"学费 6000 / 投入几十万"）
  - D. 身份标签型（"飞学长探校"系列 IP）
  - E. 痛点警示型（"不要等出分才找路"）
- 首句逐字稿
- 首帧画面（人物/B-roll/字幕板）
- 首帧字幕（顶部标题板 + 底部钩子句的具体文案）

### 维度 3：结构层（中段叙事）
- **信息块切分**：通常每块 5-15 秒一段，记下来段数
- 每段记录：口播逐字稿 + 画面描述（真人/B-roll/图文板）+ 字幕样式
- 节奏特征：每分钟切几个镜头、BGM 有无转折

### 维度 4：收尾层（最后 5 秒）
- **CTA 类型**：
  - 软 CTA（"现在准备还来得及"）
  - 硬 CTA（"评论区留 X 我私发"）
  - 转发心智（"看到最后转发给你孩子"）
  - 系列预告（"下一期带你看……"）
- 收尾画面：人物定格 / 字幕板 / 二维码

### 维度 5：视听语言
- 景别（特写/中景/全景）占比
- 字幕风格（综艺花字/极简白字/双语）
- BGM 类型与情绪曲线

### 维度 6（选做）：选题套路
- 选题来源（家长焦虑 / 政策解读 / 学生案例 / 时事热点）
- 信息密度：硬干货占比 vs 情绪渲染占比

## 横向对比（3-5 条交叉是最佳数量）

为什么是 3-5 条？少于 3 条提炼不出"共性"，多于 5 条边际收益递减。

**挑样本的规则**：
> 一类一条交叉，不要 5 条都是同骨架

例如对标一个升学规划账号，挑：
- 1 条 干货拆解（C 类骨架）
- 1 条 学员采访（B 类骨架）
- 1 条 院校解读（A 类骨架）
- 1 条 探校 B-roll（E 类骨架）
- 1 条 大盘干货（D 类骨架）

5 条覆盖 5 种不同套路，共性公式才抽得出来。

横向对比表必填字段：
| 维度 | 样本 1 | 样本 2 | ... | 样本 5 |
|---|---|---|---|---|
| 时长 | | | | |
| 钩子位置 | | | | |
| 钩子手法 | | | | |
| 顶部标题板 | | | | |
| 真人:B-roll 比例 | | | | |
| 字幕风格 | | | | |
| BGM | | | | |
| 收尾 CTA | | | | |

## 抽帧策略（已硬编码在 extract_frames.py）

不同时间段用不同抽帧密度，匹配视频的信息密度分布：

- **前 3 秒**（钩子层）：每 1 秒抽 1 帧 → 看得清标题板出现节奏
- **中段**：每 3 秒抽 1 帧 → 覆盖每个信息块至少 1 帧
- **最后 5 秒**（收尾层）：每 1 秒抽 1 帧 → 看清 CTA 字幕

输出尺寸：720×1280 → 360×640（一半），JPG 75% 质量。
- 这样 60 秒视频 ≈ 25 帧 ≈ 1.5MB，Read 起来很轻
- 字幕清晰度足够阅读

---

## 字幕还原口播的捷径

**这类口播短视频，字幕和口播 95% 同步**。直接抽帧 + 看字幕就能 80% 还原口播稿，**不需要 whisper 转录**。

只有以下场景才需要 whisper：
- 真人对话采访片，字幕只放结论
- 没字幕的纯口播片（罕见）

## 验证拉片质量

拉完之后做一次反向验证：
- **拿提炼出来的"共性公式"反向匹配对标视频**
- 如果 80% 以上的对标片能被这套公式"解释"，公式成立
- 解释不上的部分，回去补维度

如果共性公式连样本本身都 cover 不了，说明拉得太浅。重新做。
