# 单条脚本格式规范（6 模块）

> 每条脚本一个 .md 文件，必含下面 6 个模块。
> 团队拿到这份脚本就能直接开拍，不用回头问"这一段怎么拍"。

---

## 模块 1：标题 + 元数据

```markdown
# {编号} · {选题标题}

> **骨架**: A 干货拆解 | **出镜**: 飞学长 1 人 | **目标时长**: 80 秒 | **拍摄难度**: ⭐⭐
```

骨架对应 [skeleton_taxonomy.md](skeleton_taxonomy.md) 里的 A/B/C/D。

拍摄难度按外拍复杂度评：⭐ = 室内单机位，⭐⭐ = 单场地外拍，⭐⭐⭐ = 多场地或航拍。

---

## 模块 2：一句话定位

```markdown
## 一句话定位

本条片要传达的核心价值——XX 焦虑、XX 福利、XX 误区。
```

一句话讲清楚这条片**值得家长看到最后的理由**。

## 模块 3：📱 发布文案（3 平台版本）

```markdown
## 📱 发布文案

### 视频号 / 抖音版（≤110 字，第一屏可全显）

> 这里是视频号文案，简短、抓眼球、带钩子+CTA。

### 小红书版（带 emoji + 分段）

```
小红书风格的长文案。

🎯 多用 emoji 分段
1️⃣ 用 emoji 编号
👇 引导阅读

留言"XX"私发 PDF📋
```

### 公众号导流版（短视频文字稿 + 配视频）

```
完整的公众号文章版本，包含视频字幕完整文稿和导流话术。
```
```

**3 平台特性**：
- 视频号/抖音：≤110 字，第一屏全显，开头钩子
- 小红书：长，带 emoji，结构化，标签放最后
- 公众号：完整长文，可单独成文，配视频发布

## 模块 5：🎤 完整逐字稿（按段标时长）

```markdown
## 🎤 完整逐字稿

> 飞学长可以直接背或用提词器念。每段后面括号里是用时参考。

**【0-3s · 钩子】**
"XXX..."

**【3-10s · 数据铺垫】**
"XXX..."

**【10-30s · 核心点 1】**
"XXX..."

... (继续到收尾)

**【70-80s · CTA 收尾】**
"XXX..."

> 总计：3+7+20+... = 80 秒 ✓
```

**关键**：每段时长加起来等于目标时长 ±5 秒。

## 模块 6：🎞️ 分镜表

```markdown
## 🎞️ 分镜表

| 时间 | 画面 | 口播 | 字幕 |
|---|---|---|---|
| 00:00-00:03 | 真人@XX 中景 | 钩子句 | 顶部红框「XX 标题板」+ 副标「XX」+ 底部黄字「XX」 |
| 00:03-00:10 | XX B-roll | 口播段 | 中央黄字「XX」+ 红字小「XX」 |
| ... | ... | ... | ... |
| 01:18-01:25 | 真人定格 | CTA | 红字大金句「XX」+ 黄字「评论区留 'XX'」 |
```

**关键栏位**：
- 时间：MM:SS-MM:SS 格式
- 画面：人物位置 + B-roll 场景 + 取景描述
- 口播：和逐字稿一致，可简写
- 字幕：每条字幕都要标颜色（红/黄/白）+ 位置（顶部/中央/底部）+ 内容

## 模块 8（可选，推荐 A 骨架带上）：🚨 应急话术

```markdown
## 🚨 应急话术（拍摄当天忘词 / 说错时用）

| 突发情况 | 怎么补救 |
|---|---|
| 忘记具体数字 | 立即停顿 2 秒，重新说该段；剪辑用 take 2 替代 |
| 说错品牌全称 | 简称即可，全称字幕里出现一次就够 |
| 路人闯入镜头 | NG 这条，从段落开头重拍 |
| 风太大领夹麦杂音 | 立刻换有遮挡的位置 |
| 时长超出 90 秒 | 砍 XX 那句话，保留核心 |
```

## 模块 9：🏷️ 发布标签

```markdown
## 🏷️ 发布标签

视频号 / 抖音（9 个固定标签包，顺序不变）：
```
#XX1 #XX2 #XX3 ... #XX9
```

小红书额外加（长尾标签 5-8 个）：
```
#XXX #XXX #XXX ...
```
```

**视频号/抖音**：9 个固定标签包，赛道内全部视频共用，顺序不变（保品牌识别度）。
**小红书**：可以多挂几个长尾标签（去重逻辑不同）。

## ⚠️ 真假数据规范（最关键的规则）

涉及具体政策/数字（招生人数、降分幅度、学费等）的内容：

### 必须做：
- **数据来源标注**：脚本顶部加一行"数据来源：XX 官方简章 / 公众号分析"
- **占位符策略**：不确定的数字用 `[官方数据待校对]` 占位
- **数据校对表**：拍摄前 1 天填好下表，把猜测项替换成官方数据

```markdown
## ⚠️ 拍摄前必做：数据校对

| 数据点 | 当前脚本写的 | 官方数据 | 校对人 | 日期 |
|---|---|---|---|---|
| XX 录取总人数 | [待校对] | | | |
| 学考要求变化 | [待校对] | | | |
| ... | | | | |
```

### 严禁做：
- 凭空编造具体数字（会让账号失信任）
- 把"猜测"和"事实"混在一起表述
- 不标注来源就发布

## 命名规范

文件名：`{编号}_{短标题}.md`
- 编号 = 2 位数字（01, 02, ... 99）
- 短标题 = 用下划线 `_` 连接，最多 12 个汉字
- 不用空格、不用斜杠

例：
- ✅ `02_2026中大综评招生简章三大变化.md`
- ❌ `2026 中大综评招生简章三大变化.md`（有空格）
- ❌ `02. 2026中大综评招生简章三大变化.md`（有点号）
